# Jellyfin-Plugin-FixResume

(Still a WIP, this isn't perfect!)

I got tired of there being no solution to this one specific problem, so I went out of my way to make a plugin for it.
Fixes (or trys to fix) the problem of Jellyfin marking a show as watched (indicated by the blue and black checkmark) and partially watched (blue progress bar) at the same time.

# Installation instructions
Copy the link to the [manifest.json](https://raw.githubusercontent.com/DuckWithACrowbar-git/jellyfin-plugin-fixresume/refs/heads/main/manifest.json) and add it to Jellyfin.
